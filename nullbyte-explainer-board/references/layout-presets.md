# Layout Presets

Use these presets when choosing a structure for one-image explainers.

## Preset A: 3-Zone Principle Board

Best for:

- 工作原理图
- 并行 -> 合并 -> 最终结果
- 输入 / 机制 / 输出

Structure:

- title at top
- left column: `2-4` input cards
- center: one large mechanism block
- right column: result or comparison cards
- bottom: one summary strip

Use when one central idea connects everything else.

## Preset B: Step Flow Board

Best for:

- 顺序流程
- 处理步骤
- 请求 / 响应链路

Structure:

- title row
- `3-5` numbered steps
- arrows between steps
- one bottom reminder block

Use when time or order matters more than comparison.

## Preset C: Before / After Compare Board

Best for:

- 有 / 无某机制的差异
- 老方案 / 新方案
- 错误做法 / 正确做法

Structure:

- title
- left compare box
- right compare box
- center or bottom difference note
- one short verdict

Use when the teaching value comes from contrast.

## Preset D: Role / Module Architecture Board

Best for:

- Agent 角色图
- 系统模块关系
- 服务调用关系

Structure:

- title row
- center theme
- surrounding role or module blocks
- arrows or relation labels
- bottom summary

Use when the question is "谁和谁在协作".

## Preset E: Dense Note Board

Best for:

- 一张图看懂某个概念
- 需要更多注释，但还不想分页
- 用户明确给了参考图并希望保留那种手账感

Structure:

- big title
- `3-4` colored note areas
- several arrow callouts
- one bottom strip

Use when the board should feel like an annotated notebook page.

## Selection Rule

- If the concept has a central merge / reducer / router / scheduler, pick `Preset A`.
- If the concept is mostly chronological, pick `Preset B`.
- If the concept is about "without vs with", pick `Preset C`.
- If the concept is about roles or services, pick `Preset D`.
- If the user says "照这个图做" and the source is annotation-heavy, pick `Preset E`.
