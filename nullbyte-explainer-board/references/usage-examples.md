# Usage Examples

## Example 1

```text
Use $nullbyte-explainer-board 把 LangGraph Reducer 的工作原理做成一张横版图解板，参考这种可爱手绘讲解风，直接出图。
```

Expected behavior:

- choose `Preset A`
- use left inputs + center reducer + right compare result
- keep a colorful whiteboard feel

## Example 2

```text
Use $nullbyte-explainer-board 把 MCP Client 和 MCP Server 的区别整理成一张一眼看懂的对比图，先给我文案。
```

Expected behavior:

- choose `Preset C`
- output short module copy first
- keep titles short and comparison obvious

## Example 3

```text
Use $nullbyte-explainer-board 把多 Agent 工作流画成一张流程图，重点讲 planner、executor、reviewer 怎么协作。
```

Expected behavior:

- choose `Preset D` or `Preset B`
- compress roles into `3-5` clear modules
- show collaboration arrows

## Example 4

```text
Use $nullbyte-explainer-board 参考这张图的阅读感，把我这段 AI 原理说明做成新的技术图解板，不要照抄原图。
```

Expected behavior:

- choose `Preset E`
- preserve the annotation-heavy whiteboard feeling
- rebuild the wording, spacing, and block shapes

## Example 5

```text
Use $nullbyte-explainer-board 把“没有缓存”和“有缓存”的请求链路差别做成两张图，适合头条发布。
```

Expected behavior:

- produce a small bundle
- one board for no-cache path
- one board for with-cache path or one compare board
- keep the final takeaway obvious
