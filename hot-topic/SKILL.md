# 自媒体热点选题计划生成器

## 目标
根据用户指定的时间段、发布频率和内容方向，搜索当前真实热点事件，生成结构化的每日选题计划，每条选题包含：事件背景、推荐标题、写作角度和适合人群。

---

## 第一步：收集用户信息

如果用户没有明确说明，需要确认以下信息：
- **时间段**：哪一周 / 哪几天（默认本周）
- **发布频率**：每天几篇（默认每天1篇）
- **内容方向**：科技、体育、军事、社会、国际、财经、知识、教育、健康、娱乐（可多选，默认全部）
- **目标平台**：微信公众号 / 抖音 / 小红书 / 头条 / 全平台（影响标题和写作风格）
- **目标受众**：大众 / 年轻人 / 中老年 / 职场人（可不填）

---

## 第二步：搜索真实热点

**必须使用 web_search 工具**，搜索当前真实新闻，不允许凭记忆或虚构事件。

搜索策略：
1. 搜索"[当前年月] 中国热点新闻"获取综合热点
2. 按用户指定的内容方向，分别搜索对应领域热点
3. 搜索"[当前日期] 热搜"或"今日热榜"获取实时高热话题
4. 如有具体事件，进一步搜索细节

搜索关键词示例：
- 科技：`2026年 AI 人形机器人 新进展`
- 体育：`最新 国内外体育赛事结果`
- 财经：`[本月] 中国经济 楼市 股市`
- 国际：`[本月] 中美关系 国际热点`
- 社会：`[本月] 中国社会话题 热搜`

---

## 第三步：输出格式

输出必须严格按照以下格式，每天一个选题模块：

```
## 📅 [日期]（星期X）｜[内容类目]

**标题建议**：《[吸引眼球的标题，含数字/悬念/对比效果更好]》

**事件背景**：[2-3句话说明这个选题的新闻事实来源，必须是真实发生的事]

**写作角度**：[告诉作者从哪个切入点写，怎么与普通读者产生关联]

**适合人群**：[这篇文章的核心读者群]

**预期效果**：[读者为什么会在意，预计能引发什么反应]
```

---

## 第四步：输出规范

- **标题风格**：带数字、悬念、对比或"你"字，增加点击欲
  - ✅ 《存款利率跌破1%，50万亿到期，你的钱该往哪放？》
  - ✅ 《国乒男团爆冷！这次输得有多"冤"？》
  - ❌ 《关于当前经济形势的分析》

- **事件背景**：必须来自真实搜索结果，注明时间，不允许虚构
- **写作角度**：落脚在"普通人视角"——与读者生活、情绪、利益的关联
- **类目分布**：按用户指定比例均衡分配，避免连续同类
- **周末安排**：周六/周日可选择轻松类（健康、娱乐、知识科普），减少严肃时政
- **表达禁区**：不要把“值得写”“流量爆点”“这个选题”这类作者后台语言输出给读者或写进字段；日期只说明事件时间，不当写作理由

---

## 第五步：结尾补充

在计划末尾附上：
1. **🔥 备用选题 2-3条**：当热点过期或不适合时的替换方案
2. **💡 写作小提示**：本周话题的通用写作结构建议
3. **⚠️ 注意事项**：哪些话题需要注意边界，如何规避风险

---

## 注意事项

- 所有选题必须基于真实发生的新闻事件，禁止虚构
- 搜索时注意使用当前真实日期，避免搜到过期信息
- 涉及政治、军事、民族、宗教等敏感话题时，写作角度建议以"知识科普"或"正能量"为主
- 如用户只说"帮我策划"而未给更多信息，默认输出：本周、每天1篇、全类目、大众读者

---

## 兼容模式：选题候选列表

如果系统或用户明确要求：
- 返回 JSON 数组
- 只给 8-12 个候选选题
- 输出字段为 `title` / `angle` / `whyControversial` / `targetAudience`

则优先遵循系统要求，不输出“每日计划”长文格式，改为输出紧凑的选题候选列表。

此模式下的额外规则：
- `title`：适合直接写文章的高流量选题标题
- `angle`：建议从什么切口写，一句话说清
- `whyControversial`：字段名保持不变，但内容改写为“读者为什么会在意、为什么容易传播、传播钩子是什么”，不强制寻找对立和站队
- `targetAudience`：最可能点击这条内容的核心读者群
- 仍然必须先搜索真实热点，再生成候选题
