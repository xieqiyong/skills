# Style System

Use this file when the user asks for a cover "像那张图一样", wants tighter matching, or when the prompt needs a stronger visual structure.

## Core Identity

- Category: Chinese self-media AI or tech thumbnail
- Goal: maximum feed-stop power on mobile
- Tone: breaking news, authority, speed, conflict, future-facing
- Density: rich but controlled, never minimalist

## Composition Map

- Default layout: text-heavy left, hero subject right
- Secondary layout: left product or logo cluster, center conflict marker, right competitor or UI
- Keep one obvious focal point and one supporting tension point
- Use diagonal bars, slanted boxes, and angled light streaks to create forward motion

## Typography

- Main Chinese headline: very large, condensed, blocky, high-impact
- Main color: white with strong shadow or bevel
- Accent word: bright yellow or electric cyan
- Kicker strip: short red or blue banner near top-left
- Support line: white italic or boxed contrast line
- Keep text count low; size beats sentence length

## Color System

- Base: black, dark navy, graphite
- Warm accent: orange, red, amber
- Cool accent: cyan, electric blue, violet
- Use warm/cool contrast to separate factions, features, or tension

## Common Modules

- Hero portrait with rim light
- Code or app panel with glassmorphism frame
- Checklist card with bright green checks
- Versus badge or conflict marker
- Bottom feature strip with icons
- Electric crack, flare, or neon stroke at the point of comparison

## Subject Handling

- If there is a public figure, make them confident, upward-looking, and sharply lit
- If there is no person, replace the portrait with a product dashboard, code window, or abstract AI interface
- Do not overcrowd the face area; keep breathing room around the eyes and headline edges

## Copy Rules

- Use short, punchy Chinese phrasing
- Prefer contradiction, comparison, authority, or surprise
- Let one English product name carry recognition if useful
- Good structures:
  - `官方发布 + 核心对象`
  - `大词结论 + 产品名`
  - `A 正面硬刚 B`
  - `新时代来了`

## Prompt Ingredients

Include most of these in the image prompt:

- `16:9 thumbnail`
- `optimized for mobile readability`
- `oversized condensed Chinese typography`
- `dark cinematic tech background`
- `electric blue and orange/red accent lighting`
- `photorealistic subject`
- `UI panels, code blocks, feature strip`
- `dramatic contrast, glossy highlights, hard shadows`
- `premium editorial composition`

## Avoid

- Flat corporate deck aesthetics
- Pastel palettes
- Tiny captions
- Too many competing panels
- Muddy glows or low-contrast text
- Verbatim recreation of the bundled example
