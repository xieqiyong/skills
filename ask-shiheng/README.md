# ask-shiheng（编码前架构分诊 · 软件物态学）

写任何代码之前强制架构分诊：按 `[目的, 过程, 结果]` 三维相空间把每个模块分诊为 🪨固态 / 💧液晶态 / 🌊受控液态 / ☁️无界气态 / 💎制度性晶体，输出一页纸《物态架构处方单》（`PHASE_SPEC.md`）。
