# Nullbyte Tip Manual

把一组命令、技巧、配置说明或工作流经验，整理成适合头条发布的多页知识卡。核心是保留参考图那种"一眼能看懂、像手册、适合收藏"的阅读体验，再换成属于 `@NullByte·零` 的品牌语言和橙色系视觉系统。

## Recommended Inputs

优先识别下面几类输入：

- `主题`: 例如 "Claude Code 常用命令", "Cursor 提效技巧", "ChatGPT 提示词技巧"
- `原始内容`: 命令列表、配置说明、步骤、对比、笔记、截图文字
- `页数`: 例如 `1页封面`, `3页图卡`, `5页完整手册`
- `形式`: 例如 `命令表`, `步骤卡`, `避坑清单`, `组合技巧`
- `补充要求`: 例如 "右上角固定 @NullByte·零", "要更冷静一点", "适合头条"

如果用户只说"按这个风格做"或给一张参考图，默认把它理解为：`生成高相似阅读结构的技巧手册，但重写文案、重建品牌位和色彩系统。`

## Workflow

1. 先判断内容类型：
   - `命令大全`: 适合表格页，强调命令 + 一句话说明
   - `技巧清单`: 适合列表页，强调问题 -> 做法 -> 收益
   - `配置说明`: 适合模块页，强调功能块和使用建议
   - `工作流手册`: 适合多页拆分，强调顺序、组合和场景
2. 再决定输出结构：
   - `封面页`: 标题、主题解释、核心卖点
   - `内容页`: `6-8` 条命令或技巧，密度高但句子短
   - `总结页`: 组合建议、使用路径、避坑提醒、适合谁
   - `参考手册页`: 顶部细横条 + 左上小栏目名 + 右上品牌/页码 + 居中大标题 + 双列表格 + 底部说明框
3. 压缩原始内容：
   - 命令名、参数名、关键词保留原样
   - 解释缩成 `1` 句可扫读中文
   - 一页内不要塞入过多长段落
4. 保持稳定品牌位：
   - 右上角默认固定 `@NullByte·零`
   - 品牌位要清楚，但不能压过主标题
5. 如果用户明确要图：
   - 要 `提示词`、`版式方案`、`文案排版` 时，返回文本方案
   - 要 `出图`、`做图`、`直接生成` 时，调用 `image_gen`
6. 打开 `references/visual-system.md` 获取新的橙色系色彩和版式语言。
7. 打开 `references/layout-presets.md` 选择最适合当前内容的多页模板。
8. 打开 `references/usage-examples.md` 参考典型输入与输出模式。

## Defaults

如果用户没说页数，默认：

- `3页`
- `第1页`: 封面 / 总标题
- `第2页`: 6-8 条核心内容
- `第3页`: 进阶建议 / 组合用法 / 避坑提醒

如果用户没说比例，默认：

- `4:5` 竖版

如果用户没说风格，默认：

- `冷静科技编辑风`
- `暖陶橙 + 砖橙 + 米白` 色系

## Copy Rules

- 标题尽量控制在 `6-16` 个汉字
- 副标题尽量控制在 `14-28` 个汉字
- 单条解释尽量控制在 `12-26` 个汉字
- 一页内容密度可以高，但每行必须短
- 优先用"作用 + 场景 + 收益"说人话，不要堆术语

## Visual Rules

- 不照搬参考图的原始橙色系统，改用新的暖陶橙品牌语言
- 保留"手册感、表格式、易收藏"的阅读体验
- 强化标题、表格头、重点框、页码和模块分区
- 可以有英文小标题，但只能当辅助，不要压过中文主信息
- 页面角落可保留轻量页码，例如 `01 / 03`
- 右上角品牌位始终优先于页码
- 如果用户给的参考图明显就是这种"命令手册页"，优先复用这组结构语言：
  - 顶部细色条
  - 左上双语栏目名
  - 右上品牌位 + 页码
  - 中部居中大标题
  - 下方两列表格
  - 最底部圆角说明框
- 允许结构高度接近，但不要逐字照抄示例文案，也不要完全复刻边距和框体比例

## Guardrails

- 不要复制参考图的标题写法、分栏比例、提示框措辞和色块形状
- 不要逐像素复刻参考图
- 不要把整段原文不压缩地塞进图里
- 不要让所有页都长得一模一样；每页功能要明确
- 不要为了酷炫牺牲可读性
- 不要默认用荧光橙、紫色或通用 AI 海报风

## Output Modes

- 用户要 `技能卡`, `命令卡`, `知识图卡`, `技巧手册`, `海报`: 直接走视觉模式
- 用户要 `提示词`: 返回成套提示词
- 用户要 `文案`: 返回每页排版文案
- 用户要 `出图`: 直接生成图片
- 用户要 `整套`: 返回 `封面页 + 内容页 + 总结页`，必要时扩展到更多页

## Bundled Resources

- 视觉系统: `references/visual-system.md`
- 版式模板: `references/layout-presets.md`
- 用法示例: `references/usage-examples.md`

优先用参考文件来保持风格稳定，让后续同类内容可以直接复用。
