# Layout Presets

Use these presets when building a stable multi-page skill manual.

## Preset A: 3-Page Command Manual

Best for:

- command大全
- slash commands
- CLI options

Page 1:

- top thin accent line
- theme title
- scope subtitle
- why it matters

Page 2:

- top thin accent line
- `6-8` core commands
- command + explanation table

Page 3:

- top thin accent line
- `6-8` advanced commands or grouped combos
- bottom setup / usage path box

## Preset E: Reference-Like Orange Manual

Best for:

- "仿这个手册感"
- command manuals with strong table structure
- users who want very close reading rhythm to a provided screenshot

Page structure:

- very top thin green line
- upper-left bilingual kicker
- upper-right `@NullByte·零`
- optional small page marker
- centered large Chinese title
- one short centered subtitle
- rounded table block
- rounded bottom callout block

Rule:

- keep the structure close
- change the palette to warm orange
- rewrite text in your own words when possible
- do not copy the source page exactly

## Preset B: 3-Page Tips Cheat Sheet

Best for:

- usage tips
- beginner guide
- workflow habits

Page 1:

- title
- one-line conclusion
- `3` major sections

Page 2:

- `5-7` practical tips
- short explanation blocks

Page 3:

- combinations
- common mistakes
- "recommended first path"

## Preset C: 4-Page Settings Manual

Best for:

- settings explanation
- configuration breakdown
- tool onboarding

Page 1:

- title + what this setup solves

Page 2:

- core settings

Page 3:

- advanced settings

Page 4:

- recommended setup path
- pitfalls

## Preset D: 1-Page Quick Reference

Best for:

- short repostable cards
- single-topic tricks

Structure:

- title
- short intro
- `5-8` rows
- one highlight box

## Selection Rule

- If the content has many named commands, pick `Preset A`.
- If the user explicitly gives a similar screenshot and wants that manual feel, pick `Preset E`.
- If the content is more advice than commands, pick `Preset B`.
- If the content explains options and paths, pick `Preset C`.
- If the user asks for a fast single image, pick `Preset D`.
